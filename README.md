Alpha version of the Stonetop RPG module vor Foundry VTT V13.

Stonetop RPG is released by Jeremy Strandberg under the  CC BY-SA 4.0 license.

Some graphical flourishes and symbols with permission by Jason Lutes

The entire module is build around the assumption that you the GM and other 3rd parties want to add content.
You can make your own playbooks, backgrounds and inserts that populate as a tab on the character sheet.
Even players (if given permissions) can create custom inserts for their sheet and can highly customize it to their liking.


Most of the things should work fine and a lot of the compendium is populated already. 
Here is a list of things i aim to change next:

- Arcana structure. The Arcana item will be entirely reworked to incorporate textbox items, npc items and move items

- Text editor for textbox fields. I want to include more options to make the output closer to the style of the books.
  Including a bigger variety of different checkboxes and the ability to change font type, size and styling.

- Reworking the moves items to include the whole text in the description.
  When I created these, I've made the grave error of just putting the first part of the move into the description and
  the resolution is only printed when they are actually rolled. But this is merely a content managament issue.

- adding an image type item that just renders as an image on a tab inside the character sheet. that was direct community feedback.
